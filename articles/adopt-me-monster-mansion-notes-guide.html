Monster Mansion is live

Adopt Me published Monster Mansion Notes! on Friday, September 25, 2026. The update centers on a new spooky house and furniture collection, plus fixes for storage, profiles, wishlists, and Family play.

Monster Mansion price

The Monster Mansion costs 13,000 Bucks. It is a seasonal home for spooky builds and trick-or-treating, rather than a pet or value update. No new pets, eggs, or pet-value changes are listed in the official notes.

Best first move

Price the house separately from the furniture you actually want. The official notes list each item individually, so you can start with the pet-care pieces or a few decorative favorites without treating the whole collection as one required purchase.

Confirmed bug fixes

The update fixes six issues: profile pets now display Pet Wear from storage; profile items in storage can be traded directly; stored profile items can be offered for Wishlist items; display-pet NPC names stay put after a pet purchase; tall avatars can interact with low prompts; and the Family feature works normally again.

What this means for values

This is a house-and-furniture update, not a new-pet release. There is no reason to invent a pet value, update calculator data, or add a new pet page from these notes. For trade decisions, use the current trade calculator and pet value list for the pets already in your inventory.
